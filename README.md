## 📌 Project Overview

**LumiNUs** is an integrated mobile and web ecosystem developed as a capstone project for the **National University Lipa – Alumni Affairs Office**. 

The **LumiNUs Mobile App** serves as the official mobile portal for alumni, providing real-time access to university announcements, alumni networking opportunities, institutional tracer study survey forms, alumni perks and discounts, and a secure virtual identification card.

> **Note on Public Repository:** This repository contains a sanitized, showcase-ready release of the mobile application source code. All production environment configurations, sensitive API keys, signing certificates, and proprietary institutional/alumni records have been decoupled.

---

## ✨ Key Features

- 🪪 **Virtual Alumni Identification:** Dynamically renders a digital alumni ID card with verifiable QR code integration for on-campus verification and alumni privileges.
- 🗺️ **Geolocation & Alumni Directory:** Connect with fellow alumni across geographical locations with interactive location-based mapping features.
- 📋 **Institutional Tracer Studies:** Integrated, user-friendly survey modules that feed data back to institutional research and tracer analytics.
- 🎁 **Alumni Perks & Privileges:** Browse partner merchant discounts and exclusive institutional benefits offered to verified alumni.
- 📢 **Campus Announcements & Events:** Stay updated with real-time push notifications, event schedules, and official university news.
- 🔒 **Secure Role-Based Access:** Streamlined session management interacting with the centralized backend API.

---

## 🛠️ Tech Stack & Architecture

- **Mobile Framework:** React Native (Expo CLI)
- **UI & Styling:** Tailwind CSS / NativeWind
- **State Management & Data Fetching:** React Hooks / Axios
- **Mapping & Geolocation:** React Native Maps
- **Backend API:** Laravel REST API (Hosted on Railway)
- **Database:** PostgreSQL via Supabase
